# Vendorovaný zdroj OpenTTD

Tenhle adresář je kopie zdrojového kódu OpenTTD verze **15.3**
(https://github.com/OpenTTD/OpenTTD, tag `15.3`, commit
`14ec60f248547d4d062a1160f0fc26d742319888`), vložená přímo do tohoto
repozitáře 2026-08-13 (bez `.git` historie OpenTTD — další vývoj/úpravy
sleduje git tohoto repozitáře, `grrrrshadow/forclaude`).

Důvod a rozhodnutí viz `../FEATURE_DESIGN_COUPLING_TOW.md` (sekce
"Rozhodnutí padlá v diskuzi" bod 1) a `../BUILD_NOTES.md` pro to, jak se
z tohohle adresáře staví Windows `.exe` přes GitHub Actions.

Originál je vždy dostupný na GitHubu — tohle není fork udržovaný pro
zpětné sledování upstreamu, je to jednorázová kopie k přímé úpravě.
